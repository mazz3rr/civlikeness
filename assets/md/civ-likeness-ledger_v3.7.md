## 1. The Constitution (v3.4, unchanged)

**Definition:** A Civ-like is a game in which the player, as a persistent collective identity, converts a minimal foothold on an initially unknown, finite, world-scale map into a self-authored network of productive nodes whose cultivation is the game's center of gravity — in parallel competition with peers doing the same — across a long, discretely-paced timeline whose research ladder continually rewrites the rules, with several non-equivalent routes to a declared victory.

**The eight pillars:**

- **P1 — Finite, hidden, world-scale map (the commons).** Clauses: initially unknown; finite; contested commons; diegetic spatial scale. Fixed authored maps price −0.5 at high quality (TWH3/EU4 line). OTC note: three-state fog (fogged/revealed/visible) + scan phase confirmed from rulebook — hiddenness real but brief; scale remains the load-bearing dock.
- **P2 — Generative expansion.** Planting, not seizing; authored network; developed nodes; minimal-foothold arc. Acquisition tier: EU4 (diplomatic), CK3 (dynastic), TWH3 (military) — all 3.0.
- **P3 — Interior economy.** Center of gravity; self-improving nodes; evolving wide/deep dial. Max club (×9): MOO2, Civ4, Civ6, HK, Stellaris, SC4, Anno, EL, OTC (purest contested).
- **P4 — Epochal ladder.** (A) time as competition; (B) rewrites; (C) society re-encoding. Ladder-shape taxonomy: frozen · commitment · shallow-swappable · frozen-with-exits · swappable. Branch density/selectability inadmissible.
- **P5 (H) — Peer competitors.** Symmetric verbs; trajectories; diplomacy architecture; AI at equal-rules reference; no re-charging absences priced elsewhere. Max club (×5): MOO pair, Civ4, EU4, EVE, OW.
- **P6a — The collective subject.** Leak-detector. Severity ladder on file (5.0 pure → 0 none). Ingredient-vs-architecture law (−0.5 organ / −1.0 substitution / −2.0 architecture).
- **P6b (H) — Total polity, plural endings.** P6b = (polity + endings)/2. OTC's single teleology (total buyout) confirmed verbatim from rulebook. Column continuous 0.5→5.0.
- **P7 — Temporal form.** P7 = (discreteness + diegetic timescale)/2. Compression-collapse law. Discreteness sub-scale: asynchronous turns 5 · **active-pause ticks 2.5 (orders issuable while stopped)** · suspension-pause continuous 0.5 (freeze only — discretizes attention, not action). **Protocol-15 re-audit results: OTC discreteness 0.5→2.5 (SP active pause + 1 tick/second — the designer's own rulebook §3.0 "Turns"); SC2 stands at 0.5 (suspension pause only); TWH3 battles re-derived as pause-able sub-games, P7 still books 3.5; EVE no-SP exemption; all other rows already conforming.** Values: 5.0 (×14) · 4.0 (×5) · 3.5 (FM26, TWH3) · 3.0 (Anno, ItB, Sims 4) · 2.0 (SC4, EVE, **OTC**) · 1.0 (SC2) · 0.5 (Doom).

**Loop-spoke audit (derived field):** expansion↔economy · economy→ladder · ladder→capability · capability↔expansion. Worked examples on file (Civ, Anno, SC2, EU4, SC4, EVE, SMAC, BE, TWH3, OTC).

**Chassis/house:** chassis = P1+P2+P3+P4+P6a+P7 (/30); house = P5+P6b (/10). Standing column; Ch+H = Total asserted per row.

## 3. Protocols (all standing)

1. Final form declared before scoring (verified or trivially stable frozen record).
2. Pre-registration — component-derived only; non-lineage games unregistered or caveated (measured bias).
3. Anchor discipline — pull column min/max before scoring each pillar.
4. Min/max recap — every round.
5. No double jeopardy — one design decision, one clause (distinct clauses, distinct damage excepted).
6. Symmetric precedents — no engineered one-game rules; selectability inadmissible.
7. Factual negatives verified before assertion (re-affirmed: OTC pause verified from primary source before re-booking).
8. Shipped mechanics only — announced content = audit trigger.
9. No mind-reading.
10. Optional modes are house rules; the default configuration is the game.
11. Outliers-first.
12. Derivation arithmetic must sum; booking must follow the stated formula; Ch+H = Total per row.
13. Post-verification component deltas disclosed as deltas.
14. Table integrity — row-count reconciled every round-end; no row dropped silently.
15. **Single-player (vs-AI) configuration, when available, is the scored default for all pillars. Active pause (orders issuable while stopped) counts as pause-able time; suspension pause (freeze only) does not alter temporal classification. No-SP games score as-is; authored campaigns out of scope (per 10).**
16. **Attribution of error-catches and precedents cites the ledger record, not recollection.**
