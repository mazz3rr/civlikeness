## 1. The Constitution (v3.4, unchanged)

**Definition:** A Civ-like is a game in which the player, as a persistent collective identity, converts a minimal foothold on an initially unknown, finite, world-scale map into a self-authored network of productive nodes whose cultivation is the game's center of gravity — in parallel competition with peers doing the same — across a long, discretely-paced timeline whose research ladder continually rewrites the rules, with several non-equivalent routes to a declared victory.

**The eight pillars:**

- **P1 — Finite, hidden, world-scale map (the commons).** Clauses: initially unknown; finite; contested commons; diegetic spatial scale (deficits price, surpluses don't bonus). Viable-site constraints (MOO planets, Anno islands, OW city sites, EL regions) are NOT deductions — the founding verb prices. Seasonal/climate map dynamics noted (EL winters, proto-Civ6GS).
- **P2 — Generative expansion.** Planting, not seizing; authored network; developed nodes; minimal-foothold arc (one-node/inherited starts price here).
- **P3 — Interior economy.** Center of gravity = developing what one owns; solitaire optimizer; evolving wide/deep dial. Degeneracy/inversion shapes on file: ICS (Civ1/2, SMAC), corruption-wall (Civ3), global wall (Civ5, BE — Health), age-reset (Civ7), concentration tilt (Col), negotiator-inversion (EU4), character-layer inversion (CK3), war-fuel (SC2), gravity-sharing (MoM mana/armies, **OW characters**). Max club (×8): MOO2, Civ4, Civ6, HK, Stellaris, SC4, Anno, **EL**.
- **P4 — Epochal ladder.** (A) time as competition; (B) vocabulary rewrites; (C) society re-encoding. **Ladder-shape taxonomy: *frozen* (Civ5 policies) · *commitment* (BE affinities) · *shallow-swappable* (EL Empire Plan — reassigned but bonus-allocation, not re-encoding) · *frozen-with-exits* (OW laws + religion) · *swappable* (Civ governments, SMAC SE, Civ4 civics, Civ6 cards — full strength).** Branch density/selectability inadmissible (MOO2 ruling).
- **P5 (H) — Peer competitors.** Symmetric access to the game's own verbs; trajectories; diplomacy architecture; AI at equal-rules reference; no re-charging absences priced elsewhere. Max club (×5): MOO pair, Civ4, EU4, EVE, **OW — Soren Johnson holds two (2005, 2021), the only designer with two, both AI-earned**.
- **P6a — The collective subject.** Leak-detector. Severity ladder: 5.0 pure collective · 4.5 single person-leak (MOO2, Civ6, Stellaris, HK, BE/SMAC-leaders-as-interface, **EL heroes, OW [−0.5 leveling king, −0.5 person-fate-binds-state, +0.5 dynasty persistence]**) · 4.0 substitutive relay + leveling leader (Civ7) · 3.5 person-within-collective (EVE) or person-as-subject (MoM) · 3.0 person-primary + corporate credit (CK3) · 2.0 persons-inverted (Sims 4, XCOM 2, FM26) · 1.0 micro-collective (ItB) · 0 none (Doom). **Ingredient-vs-architecture law: the same person-layer prices −0.5 as organ (OW), −1.0 as identity-substitution organ (Civ7), −2.0 as architecture (CK3).**
- **P6b (H) — Total polity, plural endings.** P6b = (polity + endings)/2. New halves: OW (4.5+3.5→4.0 — faith real post-Sacred & Profane; conquest/ambition/score) · EL (4.0+4.0→4.0 — five routes incl. semi-authored quest-victory). Column continuous 0.5→5.0.
- **P7 — Temporal form.** P7 = (discreteness + diegetic timescale)/2. Compression-collapse law. SMAC/BE/OW/EL all 5.0 (turns + epochal arcs).

**Loop-spoke audit (derived field):** expansion↔economy · economy→ladder · ladder→capability · capability↔expansion, on one strategic layer. Worked examples on file (Civ, Anno, SC2, EU4, SC4, EVE, SMAC, BE; add opportunistically).

**Chassis/house:** chassis = P1+P2+P3+P4+P6a+P7 (/30); house = P5+P6b (/10). Now a standing table column (Ch/H).

Per pillar: **0 to 5.0, steps of 0.5**. Totals /40. 0 = absent; 5 = canonical. Component arithmetic in quarters; booked in halves, rounded half up, disclosed at borders. Universal: any PC game scoreable.

## 3. Protocols (all standing)

1. Final form declared before scoring (verified or trivially stable frozen record).
2. Pre-registration — component-derived only; non-lineage games unregistered or caveated (measured bias).
3. Anchor discipline — pull column min/max before scoring each pillar.
4. Min/max recap — every round.
5. No double jeopardy — one design decision, one clause (distinct clauses, distinct damage excepted).
6. Symmetric precedents — no engineered one-game rules; selectability inadmissible.
7. Factual negatives verified before assertion.
8. Shipped mechanics only — announced content = audit trigger.
9. No mind-reading.
10. Optional modes are house rules; default configuration is the game.
11. Outliers-first.
12. Derivation arithmetic must sum; booking must follow the stated formula.
13. Post-verification component deltas disclosed as deltas.
14. Table integrity — row-count reconciled every round-end; no row dropped silently.
